# OSF Grants Globe Visualization

This project visualizes OSF (Open Society Foundations) grants on an interactive 3D globe, showing grant locations, amounts, sectors, and details. The visualization is built with HTML, JavaScript, and libraries like Globe.gl for the 3D globe.

## Prerequisites

- A web server to serve the files (e.g., Python's built-in server, Apache, or Nginx). Browsers block local file access (), so HTTP/HTTPS is required.
- Modern web browser with JavaScript enabled (Chrome, Firefox, Edge recommended).
- Python 3 for running the data processing script (optional, if generating data files).

## Files Required

To run the visualization, ensure the following files are in the same directory:

### Core Files
- **osf_globe.html** - The main HTML file containing the globe visualization code, styles, and scripts.
- **three.min.js** - Three.js library for 3D rendering (downloaded locally to avoid CDN issues).
- **globe.gl.min.js** - Globe.gl library for the interactive globe.
- **papaparse.min.js** - PapaParse library for CSV parsing.

### Data Files
- **geocodes.json** - Pre-geocoded location data (latitude/longitude for grant locations). Generated by process_grantees.py.
- **grantees.json** - Grant data in JSON format (names, locations, purposes). If not present, the app will attempt to load it; generate if needed.
- **2020.csv**, **2021.csv**, **2022.csv**, **2023.csv** - Raw CSV files with grant data (recipient names, addresses, amounts, etc.). Used if grantees.json is not available.

### Optional/Utility Files
- **process_grantees.py** - Python script to process CSV files and generate geocodes.json. Requires `geopy` and `pandas` libraries.
- **geocode_cache.json** - Cache file for geocoding results (created by process_grantees.py).

## Setup Instructions

1. **Download Libraries**:
   - If not present, download the JavaScript libraries:
     - three.min.js: From https://cdnjs.cloudflare.com/ajax/libs/three.js/r150/three.min.js
     - globe.gl.min.js: From https://unpkg.com/globe.gl/dist/globe.gl.min.js
     - papaparse.min.js: From https://cdnjs.cloudflare.com/ajax/libs/PapaParse/5.4.1/papaparse.min.js
   - Save them in the same directory as osf_globe.html.

2. **Prepare Data**:
   - Ensure CSV files (2020.csv to 2023.csv) are in the directory.
   - Run `python process_grantees.py 2020.csv 2021.csv 2022.csv 2023.csv > geocodes.json` to generate geocodes.json.
   - If grantees.json is needed, create it manually or use a script to extract from CSVs (e.g., group by recipient name).

3. **Serve Files**:
   - Open a terminal in the directory containing the files.
   - Run a web server:
     - Python: `python -m http.server 8000`
     - Node.js: `npx http-server`
     - Or use any static server.
   - Access the app at `http://localhost:8000/osf_globe.html`.

## Running the Application

1. Open `http://localhost:8000/osf_globe.html` in a web browser.
2. The globe will load with bubbles representing grants.
3. Use the controls:
   - **Year Slider**: Filter grants up to a specific year.
   - **Size Mode**: Toggle between total amount or grant count for bubble sizes.
   - **Sector Filters**: Check/uncheck sectors to show/hide bubbles.
   - **Toggle Controls**: Button to show/hide the sidebar with filters.
4. Click on bubbles to view grant details in the panel.
5. Rotate and zoom the globe with mouse/touch.

## Troubleshooting

- **"Loading data…" stuck**: Check browser console for errors. Ensure geocodes.json and grantees.json load successfully. If CSVs are missing, the app may fail.
- **Globe not rendering**: Libraries (three.min.js, etc.) must load. Check network tab for 404 errors.
- **CORS or file protocol errors**: Always serve over HTTP/HTTPS, not .
- **No bubbles**: Data files may be empty or malformed. Verify CSVs have data and geocodes.json has coordinates.
- **Performance issues**: Large datasets may slow loading; reduce CSVs if needed.
- **Console errors**: Share console output for debugging.
