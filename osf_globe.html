Serve this page over HTTP/HTTPS

Your browser is blocking local file:// access, so CSVs cannot load. Please serve the folder with a simple server, then open the page via http:// or https://.

  1. Open a terminal in this folder.
  2. Run python -m http.server 8000 (or any static server).
  3. Navigate to http://localhost:8000/osf_globe.html.

This prevents the CORS error you saw when opening the file directly.
